Notificador de batería

Este script de Python te notifica sobre el porcentaje de batería de tu dispositivo.

Requisitos previos:

Necesitarás instalar Python en tu máquina. Puedes descargar Python desde python.org e instalarlo. Además, algunos otros paquetes de Python que necesitas instalar son los siguientes:

1. psutil
    > pip install psutil

2. pynotifier
    > pip install py-notifier

3. win10toast
    > pip install win10toast

Cómo ejecutar el script:

python battery.py
